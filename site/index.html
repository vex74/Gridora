01Interaction

手感，是能算出来的

所有指针交互由网格上的单个 DragGesture 驱动， 图标只负责悬停与右键菜单——从根上避免手势冲突。

01.1

拖拽跟手

拿起图标有放大、阴影与轻微倾斜；拖动时其余图标 iOS 式实时让位。

DragGesture
01.2

拖到中心＝合并，拖到间隙＝重排

松手自动合成文件夹；合并目标在其槽位画白色圆环提示，可打开、重命名、解散、移出成员。

中心 / 间隙
01.3

合并判定用布局快照

目标取自拖拽开始时的布局，不会在网格重排中从手下「逃跑」。

dragBase
01.4

自然滚动翻页

触控板双指、鼠标滚轮都能翻页，带橡皮筋与回弹吸附；可切纵向滚动模式。

横向 / 纵向
01.5

拖到边缘自动翻页

图标停在屏幕左右边缘 0.4 秒，自动翻到相邻页。

400 ms
01.6

点空白回桌面

点图标才打开 App，点空白处直接收起启动台——与 Launchpad 一致。

Esc
02Control

参数不是装饰，是真的能改

设置改动即时生效并自动保存，写进独立目录的 state.json。 下面每个区间都来自设置面板的实际范围。

4–9每行图标数
3–7每页行数
78–118%图标大小
0.4–2.0×滚动速度
02.1

拼音搜索

按任意字母直接进入搜索，支持中文名、拼音全拼与首字母（wx → 微信），方向键选择、Return 打开。

⌘F / 字母
02.2

隐藏不常用 App

右键隐藏，或按闲置天数自动收进隐藏区；隐藏项不出现在网格和搜索里，恢复后受保护不再自动隐藏。

⌘⇧H
02.3

外观可调

程序化极光背景（不读桌面文件、不弹权限框）；可选模糊桌面壁纸，模糊度与暗度独立可调，标签可隐藏。

极光 / 壁纸
02.4

分组式设置面板

通用 / 外观 / 布局 / 应用位置 / 已隐藏 App / 关于 六类，浅色分组卡片，记住上次浏览位置。

⌘,
02.5

应用位置扩展

可添加外置硬盘等自定义 App 目录，保存后自动重扫描；一键开机自启（SMAppService，macOS 14+）。

SMAppService
02.6

Dock 常显 · 多屏 · 失焦收起

窗口层级位于 Dock 之下，网格为 Dock 留底部内边距；每次唤起按鼠标所在屏铺满，切到别的 App 自动隐藏。

kCGDockWindowLevel=20
03Keyboard

手不用离开键盘

方向键在网格中定位，Return / 空格打开；Home / End 到首尾， ⌘1…⌘9 直接跳页。搜索框支持 ↑↓←→ 选择。

04Build

从源码到全屏，两条命令

当前以源码分发，没有在线安装包。build.sh 会组装 .app、写入 Info.plist、拷贝图标并做 ad-hoc 签名。

zsh — LaunchOS-源代码 
$ ./build.sh
$ open build/Gridora.app
# 或只编译：swift build
Sources/LaunchOS/
├─ App/     Main.swift · AppDelegate.swift · GlobalHotKey.swift
├─ Model/    Models.swift · LauncherModel.swift · AppScanner.swift · StateStore.swift
├─ Views/    LauncherView / PagerView / TileView / 四个浮层 / 组件
└─ Support/ DebugHarness.swift

要求 macOS 14.0 及以上。应用扫描 /Applications、/System/Applications、 ~/Applications 及自定义目录，跳过 LSUIElement 后台程序。 状态文件位于 ~/Library/Application Support/com.vex.launchos/state.json， 删除该目录即可恢复首次启动状态。
